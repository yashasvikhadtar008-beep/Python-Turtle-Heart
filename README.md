# 💜 Python Turtle Heart

A simple Python graphics project that uses the **Turtle module** and **mathematical equations** to draw a heart shape.

## 📌 About the Project

This project demonstrates how mathematical equations can be combined with Python Turtle graphics to create a visual heart-shaped pattern.

The program calculates the **X and Y coordinates** of points using sine and cosine functions and then moves the Turtle to those coordinates to create the heart shape.

## ✨ Features

- 💜 Draws a heart shape using Python Turtle
- 🧮 Uses mathematical equations with sine and cosine
- 🎨 Uses a black background with a purple heart
- 🐢 Demonstrates Turtle graphics
- 🔁 Uses loops to generate multiple points
- 📍 Uses X and Y coordinates for drawing

## 🛠️ Technologies Used

- **Python**
- **Math Module**
- **Turtle Graphics**
